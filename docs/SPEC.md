# AgroSim: Якісні реакції з визначення добрив — специфікація (скорочено)

Повний вихідний майстер-промпт v1.0 — у власника проєкту; тут зафіксовано ключові вимоги.

## Розділи
1. **Теорія** — основи якісного аналізу, аналітичні ознаки, картки реакцій (NH₄⁺, NO₃⁻, PO₄³⁻, K⁺, SO₄²⁻, Cl⁻, Ca²⁺).
2. **Віртуальна лабораторія** — пробірка, реактиви, нагрівання, анімації (осад, газ, буре кільце, розчинення), режими «покроковий» і «самостійний».
3. **Ідентифікація** — невідомий зразок, матриця «добриво × йон», повідомлення про недостатність/суперечність результатів.
4. **Перевірка знань** — 4 типи завдань, 10 балів (1 реактив, 2 інтерпретація, 3 ідентифікація, 3 послідовність, 1 висновок).

## Добрива (MVP)
NH₄NO₃, (NH₄)₂SO₄, NH₄Cl, KNO₃, KCl, K₂SO₄, простий і подвійний суперфосфат, NH₄H₂PO₄, (NH₄)₂HPO₄, сечовина.

## Хімічні вимоги
Дивись `.cursor/rules/agrosim-qualitative.mdc`. Бібліографія — лише реальні джерела, вносить викладач.

## Технології
React 18, TypeScript strict, Vite (`base: './'`), Vitest, ESLint, Lucide, GitHub Pages. Без серверної частини.
